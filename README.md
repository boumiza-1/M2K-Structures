# M2K Structures — Site vitrine

Site vitrine bilingue français/arabe pour M2K Structures, avec une direction artistique architecturale sombre, animations discrètes, galerie de projets, navigation responsive et premiers réglages SEO.

## Fichiers
- `index.html` : contenu, métadonnées SEO, données structurées et sections.
- `styles.css` : design responsive et animations.
- `script.js` : navigation mobile, bascule FR/AR, animations au défilement.

## À vérifier avant mise en production
1. Remplacer les images d'illustration Unsplash par les photos exactes du PDF. Les photos de la maquette ne sont pas garanties comme étant des réalisations de M2K.
2. Confirmer le domaine canonique `https://m2k-structures.com/` et configurer redirection HTTPS/www selon le domaine retenu.
3. Confirmer l'adresse physique, la zone d'intervention exacte, les horaires et les services avant d'ajouter des informations locales.
4. Tester les coordonnées, les liens WhatsApp/téléphone, les images, l'affichage arabe, les performances et les métadonnées.
5. Ajouter un sitemap.xml, robots.txt, favicon, image Open Graph dédiée et Google Search Console avant le lancement.
6. Vérifier les licences et l'hébergement des images externes; pour la production, privilégier les images optimisées stockées dans le dépôt.

## Déploiement
Le site est statique : déployable sur GitHub Pages, Hostinger (hébergement statique) ou autre hébergeur compatible HTML/CSS/JS.
